# Aero VPN — 安卓免费境外 VPN 搜索与连接

简洁浅色界面，内置 OpenVPN 原生内核，**无需安装另一个 VPN 客户端**。
支持 Android 8.0+ 的 ARM64 手机，以及 x86_64 模拟器。

## 功能

- 通过 HTTPS 获取日本筑波大学 VPN Gate 的动态免费节点目录，不使用虚构地址。
- 默认过滤地区代码 CN、HK、MO，过滤重复、异常地址和不安全配置。
- 搜索国家（支持常见国家的中文名）、IP、节点名称；按地区筛选。
- 推荐 / 延迟 / 速度排序、本地收藏、刷新以及一小时离线缓存。
- 选择节点后在应用内连接、取消或断开；首次使用需安卓系统 VPN 授权。
- 显示内核返回的真实连接状态与累计流量；不会把“正在连接”显示为“已连接”。

节点数量随目录变化，应用没有人为设置小数量上限。国家、延迟与速度是目录报告值，
不等于独立地理验证或本机测速。免费志愿者节点可能离线、拥堵或记录访问。
应用没有账号、广告或统计 SDK；缓存和收藏保存在本机。

## 构建

1. 安装 JDK 21、Android SDK 36、Build Tools 35.0.0、NDK 29.0.14206865 和 CMake 3.22.1。
2. 在本目录运行 `python3 scripts/prepare_engine.py`，获取固定版本的内置 VPN 内核及其子模块。
3. 在本机通过 Android Studio 打开项目，或设置 `ANDROID_HOME` 后运行：

   ```sh
   ./gradlew :app:assembleDebug :app:testDebugUnitTest :app:lintDebug
   ```

提供的完整源码压缩包已包含准备好的 `.engine/`，解压后也可离线使用这些内核源码。

4. APK 位于 `app/build/outputs/apk/debug/app-debug.apk`。这是开发签名安装包，正式发布需使用自己的签名配置。

在本云工作区可用已验证的工具链：

```sh
cd /workspace/123
python3 scripts/bootstrap_cloud.py
python3 scripts/prepare_engine.py
python3 scripts/cloud_gradle.py :app:assembleDebug :app:testDebugUnitTest :app:lintDebug
```

工具链安装脚本验证官方归档的校验和，保留 TLS 校验，通过系统信任库使用云代理。
它不会修改 HOME，也不会保存代理凭据。`local.properties` 和 `.engine/` 是忽略的本地生成文件。
如果 Oracle 的 latest JDK 归档更新导致固定校验和不匹配，脚本会停止；需核验官方新版本后更新固定版本。

## 验证

11 项单元测试覆盖地区排除、中文搜索、CSV 引号、去重、异常记录、未知延迟、内网地址、
远端匹配、内联证书要求及脚本/插件注入拒绝。

真实 VPN Gate HTTPS 获取和缓存读取已验证；APK 的两个 ABI 均包含原生 VPN 库和可执行文件。
安装和启动已在 Android 9 与 Android 15 模拟器验证。云模拟器不能直接解析节点源的 DNS，
界面验证使用宿主机通过 HTTPS 下载的真实节点列表作为离线缓存，并在界面标注缓存。
应用只接受 HTTPS 节点源，没有降低证书或包校验要求。
模拟器中的 IP 搜索、收藏保存与节点选择已验证；原生 OpenVPN 程序已运行并输出正确版本。
云模拟器没有硬件加速，系统界面出现卡顿；系统 VPN 授权与内核启动已验证；所选节点的 TCP 连接被拒绝，真实隧道尚未连通验证。
连接时额外启用标准的 TLS 服务端证书用途检查（`remote-cert-tls server`），不降低证书校验。

不要把节点目录可访问等同于每个 VPN 节点都可连接。真实手机上的连接质量依赖节点在线状态、
运营商网络以及安卓系统授权。

### 1.1.0 更新

- 节点连接超时、DNS 和 TLS 错误使用中文提示；刷新按钮保持单行。
- 支持通过系统文件选择器导入 VPN Gate 原始 CSV 列表（最大 12 MB），继续执行境外地区及配置安全校验。可在能够访问官方网站的网络下载 `https://www.vpngate.net/api/iphone/` 的原始内容，保存为 CSV 后传到手机导入。导入不是第二个在线节点源，不能解决节点服务器自身不可达的问题。
- 缓存可浏览 24 小时，超过一小时须更新后连接；更新失败保留现有列表。
- 此版没有内置过期节点或使用未经验证的镜像。真实 VPN 隧道连通仍需在手机网络测试。

### 1.2.0 节点获取更新

- 首次启动先加载安装包中的真实节点快照，不再依赖首次成功连接 VPN Gate。快照保存原始采集时间；七天后不再接受，超过一小时连接前明确提示可能已失效。
- 同时查询官方 HTTPS API、本项目 GitHub Raw 和 GitHub 下载入口，采用第一个通过格式、地区及配置校验的结果。三个渠道分发同一 VPN Gate 目录，不是三个独立 VPN 服务商。较旧的备用列表不会覆盖较新的本地列表。
- GitHub Actions 每小时计划更新 `nodes/vpngate.csv`，也可手动触发 `Refresh public VPN Gate directory`；GitHub 可能延迟计划任务，失败时保留旧列表。管理员需要在仓库中启用 Actions；此更新不需要 VPN 账号或密钥。
- `python3 scripts/update_nodes.py --bundle` 在构建前同时更新公开目录和 APK 快照。仅运行不带参数的脚本更新在线目录，不会重新生成 APK。
- GitHub 获取渠道也可能在手机网络不可达。离线节点能被搜索不代表能建立隧道；本版本不承诺可连接节点数量，仍需真机测试。

### 1.3.0 可用性验证、自动选择与取消修复

列表仅显示**本机最近十分钟建立了 OpenVPN 隧道并通过隧道绑定的 HTTPS 联网请求**的节点。不再把目录中公布的节点、TCP 端口可达或 UDP 发送成功当作“可用”。点击“检测可用节点”并接受安卓系统 VPN 授权后才开始检测；如果本机网络上没有节点通过验证，列表应为空。

“自动选择最优节点”开关启动前台服务，每十分钟计划重新检测。每轮先检测 TCP 端口，再依次测试最多十二个可达候选，八分钟扫描预算内轮换候选。UDP 必须实际握手，端口检查不能证明可用。每个成功隧道发起 HTTPS 请求，并尝试下载 256 KB 样本，显示本机 HTTPS 耗时与样本速度。选取本轮样本中较优节点；改善不足 20% 时保留原有较优节点，避免小波动频繁切换。它不代表对所有节点的完整排名。

安卓同时只允许一条 VPN：检测其他节点会短暂断网并切换隧道。普通检测结束后恢复原先的节点；开启自动模式则连接本轮选出的节点。每轮最多约 3 MB 下载样本，此外有握手与验证流量。通知可停止检测并断开。切换底层网络会作废此前验证结果；证据不会跨进程重启持久保存。系统省电、用户强制结束进程或厂商后台限制可能延迟或停止十分钟计划，需要允许后台运行。

取消按钮立即废止当前任务，关闭自动模式，并重复请求 VPN 内核停止，等待稳定的断开状态，防止管理接口尚未启动时的停止请求被忽略。无法确认退出时明确提示到手机 VPN 设置中断开，不伪装取消成功。连接经过 `VpnService.prepare` 系统授权，内置 `OpenVPNService` 建立系统隧道；只有隧道内联网验证通过才显示已验证联网，不用界面动画模拟系统 VPN。

### 1.3.1 检测诊断

点击自动开关下方的状态文字，查看本轮端口不可达、隧道未建立、隧道内 HTTPS 联网失败的数量，以及最多八个节点的失败原因。诊断不收集账号、配置或密钥。该版没有加入未经验证的独立服务商，也不将数量增加误称为可用性增加。

### 1.4.0 隧道实测下载速度

- 每个通过隧道 HTTPS 联网验证的节点继续实测响应体下载速度，优先使用 Cloudflare 的 1 MB 样本，失败后尝试 GitHub APK 文件的前 1 MB。请求禁止压缩并限制读取量，连接与 TLS 建立时间不计入响应体测速；每次测速两条渠道合计读取至多约 2 MB，另有协议流量。
- 测速持续至 1 MB 样本完成或八秒时间预算结束，收到至少 64 KB 才形成结果，显示实际收到的样本大小、Mbps 和验证距今秒数。HTTP 错误、小错误页、压缩响应、取消和网络变化不会伪装成成功测速。
- 节点卡片分行显示实测 HTTPS 耗时与下载速度；“当前 VPN 测速”按钮可重新测量当前隧道，无需切换其他节点。十分钟自动选择使用新的实测值。速度是对指定测速地址的短时样本，不是节点公布速度或所有网站的最高速度。
- 旧版 256 KB 与每轮约 3 MB 的说明不适用于此版。每个成功节点的样本预算提高；移动数据网络上需要考虑实际检测次数。VPN 节点未能建立隧道时无法实测速度，不显示虚构数值。

### 1.5.0 手动搜索与独立免费来源

- 将主操作改为“搜索可用节点”，成功建立隧道并验证联网、测速的节点边搜索边显示在下方。用户手动选择连接；删除自动选择开关与十分钟扫描、自动切换逻辑。搜索完成时恢复原先的连接，不自动连接搜索出来的新节点。
- 保留当前 VPN 测速、下载 Mbps、样本大小与验证时间，以及搜索诊断。十分钟只是验证结果的有效期，不再触发定时扫描。
- 新增真正独立的 **VPNBook** 官方 OpenVPN 来源：`https://www.vpnbook.com/freevpn/openvpn`，读取官方服务器目录并下载 TCP 443 单文件配置。发布时目录含十台服务器，地区为美国、加拿大、英国、德国和法国；数量可能变化，未声称已在用户网络连通。与 VPN Gate 候选交错搜索，避免一个来源占满尝试额度。
- VPNBook 使用官网公开共享账号。当前共享密码需要官网的人机验证；在“节点来源 → 获取官网密码”中自行完成，然后回到来源设置保存密码。应用不会绕过验证，也不捏造账号；未设置密码的 VPNBook 候选跳过连接并在诊断中解释。共享密码使用 Android Keystore 的 AES-GCM 加密，仅在手机应用私有目录存储，不随节点缓存、GitHub 源码或诊断上传。官网更换密码后需要更新。
- 继续使用 HTTPS、来源域名与配置校验、CN/HK/MO 和内网地址排除。新增可接受的 `auth-user-pass` 仅允许无文件参数的交互式认证；不允许读任意本地密码文件。配置安全通过不代表节点能连接，列表仍只显示本机近期验证成功的节点。

### 1.6.0 并发搜索，无需逐个建立 VPN

- 搜索只获取目录并使用手机底层网络最多 16 路并发检查 TCP 端口，每次连接超时 2.5 秒。发现可达节点后立即显示下方，不要求 VPN 授权、不发起 VPN 隧道、不切换或断开当前 VPN。停止搜索仅取消探测。
- 卡片明确区分“TCP 可达 · 待连接验证”和“联网验证通过”。端口可达不能证明 VPN 认证或互联网访问成功；选中连接时才请求系统 VPN 授权，验证隧道 HTTPS 联网并测速。未连接的节点没有下载速度数据。
- 不把 UDP 发包当作成功检查，UDP-only 配置不加入 TCP 可达结果，搜索状态显示跳过数量；不保证免费节点一定能用。VPNBook 搜索无需密码，连接仍需在节点来源保存官网当前共享密码。
- 保留手动连接与测速，不自动选择节点；历史章节的逐个隧道搜索说明不适用于此版。

### 1.6.1 连接生命周期与快速搜索

- 修复断开完成后停止标记未复位、绑定服务仍存活时无法再次连接的问题；断开期间禁用重复点击，完成后恢复操作。停止旧启动请求时仍等待内核稳定退出，首次连接没有旧隧道时不再等待空停止。
- 搜索优先读取有效缓存，避免每次点击等待全部来源下载；“刷新”更新来源后可再次搜索。并发探测提升至 24 路，端口超时缩短到 1.8 秒，探测阶段预算 30 秒（来源无缓存时另需下载时间）。缩短超时可能漏掉当前网络响应较慢的服务器，可刷新或重试。
- 保留真实 VPN 联网校验及测速，不承诺免费节点的连通性或带宽。

### 1.6.2 断开后重新创建连接内核

- 移除界面对内核服务的冗余绑定；断开确认后解除连接服务的绑定并停止旧内核服务，清空旧连接 UUID 与状态。再次连接时重新绑定、等待新内核就绪，避免复用旧会话。
- 连接失败直接显示实际原因，区分认证失败、内核未就绪、握手超时及隧道联网验证失败。需要在用户手机上复测连续连接、断开、再次连接；云端构建不能证明免费服务器当前可用。

### 1.6.3 同一节点重连与连接状态

- 取消一次重试后退出的内核限制：同一节点采用 3 秒起步、最大 30 秒退避的重试，保留 TUN；用户断开仍停止内核，不自动选其他节点。首次握手仍有 30 秒预算，首次联网验证最多重试三次，减轻网络切换或验证地址暂时超时造成的退出。
- 手机系统隧道状态与十分钟测速证据有效期分开，避免证据过期时将仍建立的隧道显示成已断开。证据过期或网络变化仍要求重新测量，不把旧验证结果当成当前联网保证。
- 免费服务器离线、运营者踢连接及手机后台限制仍可能导致断线，尚未在用户手机复测。

### 1.7.0 APK 对照分析与开源免费来源

- 分析附件 WroldPass Free VPN 2.0.3：Clash + Android VPN 接口，支持代理测试和回退，与 Aero 的 OpenVPN 配置不通用。分析报告见 docs/reference-apk-analysis.md；未复制其二进制或非公开账号。其 GitHub 配置地址当前返回 404，不能作为节点来源。
- 新增 RiseupVPN 官方 LEAP v3 匿名 API 来源。客户端及提供者信息来自开源 LEAP Bitmask；API 要求固定提供者 CA 和正常域名校验，禁止跳转。匿名证书与私钥仅保存在手机私有缓存，不进源码、报告或 GitHub。缓存最多六小时且校验证书有效期，排除 CN/HK/MO、私网地址、非 TCP / OpenVPN 配置；不上报未获得的实时节点数量。CA 期限与指纹见 third-party/leap/NOTICE.md，过期时拒绝连接并要求更新。
- 云环境无法访问 Riseup API，因此该来源尚未进行实时获取或手机连接验证；手机刷新成功才会加入候选，否则显示来源暂不可用。其开源客户端不等于任何免费节点都稳定或可达。
- 已建立且仍处于 CONNECTED 的系统 VPN，不再仅因外部 HTTPS 验证地址暂不可达而主动关闭；显示“联网验证暂未通过”，保留手动测速及断开。认证失败、内核退出与手动取消仍正确停止。保持手动选择，不恢复自动切换节点。
