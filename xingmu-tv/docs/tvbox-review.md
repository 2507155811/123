# TVBox 聚合配置兼容范围

参考：https://github.com/Lightconer/tvbox-ysc-config

本次读取公开仓库 output/单仓聚合.json，不下载或执行 spider/JAR/parses 的代码。配置有 167 个站点，9 个 type 1 标准 API，158 个 type 3 Spider 站点，7 个直播配置项，33 个解析配置。

## 已实现数据兼容

- 文件和 HTTPS 配置网址导入，独立保存标准 API 与外部直播列表，保留旧媒体目录。
- 标准影视 API 搜索（MacCMS JSON/XML），最多 3 路并发、18 秒整体超时；分类、年份和来源显示，列表最多 120 项。
- 详情与剧集解析，多个播放组同名剧集合并为备用地址，直接流交给 Media3；未返回直接地址则说明需要解析插件。
- 直接直播 channels/urls 导入；外部 M3U/TXT 列表通过更新按钮拉取，各列表独立失败和合并，旧目录不会因失败清空。
- 不加载 Spider/JAR/parses，不支持 proxy://、自定义请求头、EPG、多仓订阅或加密配置。API/播放地址需满足公开 HTTP/HTTPS 校验，列表更新与搜索不会访问私网字面地址。

文件导入原始配置可识别 9 个 API、4 个绝对直播列表网址；网络导入可解析 6 个网址，其中 2 个为相对路径。内联直播是 proxy:// 包装而非直接流，没有把它当成已可播放频道。相对路径是否存在、源是否存活与媒体是否可解码需要实际网络验证。

用户导入是数据格式转换，不代表所有站点能使用。未在小米电视或真实影片上确认此仓库媒体的播放情况。不会将配置请求成功、搜索结果、HLS 清单响应速度标为可播放或真实 Mbps。

验证结果：44 项 JUnit 测试通过、lint 0 错误、APK 签名校验通过。实际参考文件已在 Android 9 模拟器通过系统文件选择器导入，应用保存报告显示 9 个标准 API、4 个外部直播列表、158 个未支持插件站点和 3 项不支持地址。没有验证该仓库媒体的实际播放或带宽。
