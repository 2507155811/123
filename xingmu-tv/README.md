# 星幕 TV

独立的 Android 电视、手机和平板项目。最低 Android 5.0 / API 21，编译 API 36、目标 API 35，使用 AndroidX Media3 1.6.1，无 VPN、账户后台、广告或统计 SDK。电视首页提供国内直播、网络影视、国外直播，支持遥控器；手机和平板根据可用宽度采用一至三列，支持横竖屏。广泛兼容是实现目标，不能等同于全部型号已经实测。

## 内容与播放能力

- 内置 17 个央视官方观看入口、5 个国际频道官方观看入口，国外内容按国家分类。它们是官方网页，不是声称已验证可用的原生直播流；页面可能需要点击播放、登录或官方应用，也可能不支持电视 WebView。设备没有 WebView 时会解释原因。
- 内置 4 部 Blender 开放电影，分类动画、奇幻、科幻，按 Creative Commons 授权播放并显示署名。Google 公共视频样本作为 MP4 分发来源；归属与许可保存在目录内。影片项目：https://www.blender.org/about/projects/ 、https://studio.blender.org/films/ 。各作品的音乐等单独素材可能有额外条款，本应用仅播放成片，不再分发独立素材。
- Media3 原生播放器支持公开 HTTPS MP4、HLS、DASH，保存点播进度，直播错误最多退避重试三次。左右键（控制条隐藏时）、频道键、媒体上一项/下一项切换当前分类的内容；屏幕按钮同样可操作。官方网页由 WebView 按提供者权限与规则观看，未破解 DRM 或会员授权。
- 不接入盗版 VIP 聚合、未经授权转播或付费解析接口。“开源播放器”不意味着其接入的节目获得授权。没有内置 VPN也不意味着所有国际来源都能跨地区直连；地区、设备及网络限制仍然有效。

## 开机进入与默认桌面

默认不更改系统桌面。用户在设置中打开“开机进入星幕 TV”。首次安装需先打开应用一次，允许系统通知与厂商自启动。收到 BOOT_COMPLETED 后使用普通系统 API 尝试启动；同时准备通知入口，成功进入主界面后取消通知。Android 10 及以上可能因后台界面启动限制而被系统拒绝，不声称能强制自动打开；厂商允许自动启动时仍会进行启动尝试。小米/其他厂商可能另有限制，某些电视也没有可见通知入口，需要实机设置和验证。

另外提供“可选：设为默认电视桌面”：明确说明后启用 HOME 候选，用户在系统设置自行选择。部分系统不允许更换；不会使用 root、禁用系统桌面或绕过系统限制。设置页提供关闭 HOME 候选的操作；更改默认桌面前应确认能访问原系统设置。手机不建议把本应用替代完整桌面。

## 已授权内容导入

从文件或公开 HTTP/HTTPS 地址导入 JSON。自定义目录可覆盖同 ID 内置项目。只应导入拥有观看权限、获公开播放许可的内容；`authorized: true` 是用户声明，并非本应用独立审核的版权证明。原生直播可使用获授权的 HLS/DASH/MP4 URL，网页入口仅允许支持名单中的官方域名。暂不支持 TVBox 爬虫、VIP 解析、加密会员接口或任意插件。

```json
{
  "authorized": true,
  "items": [
    {
      "id": "my-authorized-channel",
      "title": "已授权直播",
      "section": "domestic",
      "category": "新闻",
      "country": "中国",
      "mode": "stream",
      "url": "https://your-authorized-provider.example/live.m3u8",
      "source": "提供者名称",
      "license": "已取得观看授权，遵守提供者条款"
    }
  ]
}
```

`section` 为 domestic / foreign / films；国外按 country 分组，其他按 category 分组；`mode` 为 stream / official。单目录最多 1 MB、1000 项。限制 HTTPS、无 URL 账号密码及本地/私有 IP；不携带浏览器会话或破解请求头。实际配置由用户授权来源提供，示例 URL不是可用频道。导入会替换此前自定义目录，内置目录不受影响。

## 开发环境

常规开发使用 JDK 17+、Android SDK 36 与 Gradle Wrapper，配置 SDK 后执行：

```sh
./gradlew :app:assembleDebug :app:testDebugUnitTest :app:lintDebug
```

当前云环境保留在 `/workspace/toolchains`，运行以下已配置代理与系统 TLS 信任的命令：

```sh
python3 scripts/cloud_gradle.py :app:assembleDebug :app:testDebugUnitTest :app:lintDebug
```

不修改 HOME，不关闭 TLS 校验。不需要运行后台服务或提供密钥。APK 与完整源码压缩包放在 artifacts/。这是独立项目，没有写入 Aero VPN 仓库，也尚未创建新的 GitHub 仓库。应用包名 `org.xingmu.tv`，与 VPN 软件可同时安装。当前 APK 是开发签名包，不是应用商店发布包。

## 戏曲频道

首页增加戏曲专区，跨来源聚合京剧、豫剧、越剧、粤剧、黄梅戏等分类的授权点播。直播仅纳入分类为戏曲且来源声明 `operaOnly: true` 的纯戏曲节目流；普通混播频道不被当成全天纯戏曲。来源声明不能独立证明正在播放的节目，提供者应对内容与授权负责。CCTV-11 官方入口保留在国内直播，因缺少实时节目单，不自动加入严格戏曲专区。当前没有附带经核实的纯戏曲免费源，专区初始为空，不会填入虚构或盗版地址；授权目录可补充。

## 安装

手机或平板打开 artifacts/XingmuTV-debug.apk；电视可通过 U 盘或厂商支持的文件传输方式安装同一 APK。允许系统要求的安装来源，打开“星幕 TV”。开机进入与默认桌面均在设置中由用户选择，默认不强制启用。Android 5.0 以下不能安装。

## 1.1 浏览与播放优化

首页增加最近观看与收藏；分类页支持搜索、来源和内容类型联合筛选，手机/平板/宽屏按 1 / 2 / 3 列显示。遥控器菜单键或长按内容卡片收藏，播放器菜单键打开播放选项。直接视频支持断点续播、0.75–2 倍速、画面比例、失败重试及可选自动播放下一项（设置中开启，默认关闭）。观看记录只保存在本机，可在设置中清除。

参考项目分析见 [LibreTV-App 分析](docs/libretv-review.md)。本次没有导入其聚合影视源。

直播稳定性增加同频道最多 8 个播放地址、成功地址记忆、当前源重试和备用源切换；直播长时间缓冲时恢复，换台按键防连击。参考 [TVLive 分析](docs/tvlive-review.md)。

## 我的多格式播放列表

设置提供文件选择、HTTPS 远程列表、粘贴文本三种入口。支持：

- 原有 JSON 目录（`authorized: true`、`items`、每项 `license`）；新增可选 `backupUrls` 数组，最多 7 个备用公开 HTTP/HTTPS 地址，仅用于 `mode: stream`。
- M3U / M3U8 **频道列表**：`#EXTINF` 名称、`group-title` 分组、`tvg-country` 国家；真正 HLS 分片清单应使用它的播放 URL。
- IPTV TXT：`分类,#genre#`、`频道名,https://…`；也支持 `片名$https://…` 每行一项。
- XSPF：`trackList/track/title/location/album`，支持标准 XML 命名空间。
- 单个公开 HTTP/HTTPS MP4 / HLS / DASH 地址。

非 JSON 列表先选择国内直播、国外直播或网络影视栏目及国家；分组保留，戏曲点播按戏种进入戏曲栏目。纯戏曲直播仍需 JSON `operaOnly: true`，避免把混播台全部当戏曲。

每次导入合并现有目录，同 ID 更新；同文件同名同分组的多个地址合并为备用源。最多 1000 项、1 MB，不执行 TVBox 插件、JS、JAR 或解析站。直接地址支持公开 HTTP/HTTPS，不支持内网、UDP/RTSP；HTTP 仅用于媒体流，官方网页与远程目录导入仍使用 HTTPS。普通 M3U/TXT 不含授权字段，导入入口要求用户拥有媒体访问权；JSON 保留授权字段校验。

TVBox 配置的标准 `type: 1` 影视 API 和直接直播部分可导入；`spider / parses` 可执行插件尚不支持，不会把配置下载成功当成可以播放。

## 1.2 TVBox 配置导入

设置 → **导入 TVBox 配置文件**，选择单仓聚合 JSON；也可在 HTTPS 导入入口填写单仓配置网址。通过 **TVBox 导入报告与直播更新** 查看支持范围，并更新直播列表。打开 **网络影视 → 搜索 TVBox 网络影视源**，输入片名，选择所有支持 API 或单个来源，选择影片、剧集后直接播放。

支持标准 MacCMS JSON/XML 影视 API（`sites[].type: 1`）、`lives[].url` 外部 M3U/TXT 列表、`lives[].channels[].urls` 直接频道。远程导入支持相对直播路径；本地文件中的相对路径没有远程基址，会显示不支持。导入 API 不会立即连接所有站点，搜索由用户触发；最多 3 个并行请求、18 秒整体等待，失败源不会让所有结果消失。影片列表和直接地址仍不代表真实可播放。

参考配置快照有 9 个标准 API、158 个插件站点；本地文件能识别 4 个外部直播列表网址，远程地址导入能解析 6 个（其中相对路径是否实际存在仍需更新验证）。Spider/JAR、VIP 解析、proxy://、复杂请求头/Referer、EPG、加密配置及多仓订阅不支持。不会下载或运行配置里的脚本或 JAR。

更多分析：[TVBox 配置兼容范围](docs/tvbox-review.md)。

## 1.3 界面与加载重构

首页改为深色影院视觉、原创矢量主视觉、独立栏目卡片；影视使用海报式卡片，直播使用紧凑频道卡片。遥控器选中有描边、轻微缩放和阴影；手机、平板与电视按屏幕宽度调整栏目与内容列数。海报背景为应用原创图形，不冒充电影原版海报。

已接入用户指定的 [myIPTV](https://github.com/suxuang/myIPTV)，内置 ipv4.m3u 的 c70ac1dc42aad924c44afdf6476a4b2d4b1d980d 快照：1,108 项目录，国内频道 1,045、国际频道 51、点播 12；52 项不支持的地址跳过。支持公开 HTTP/HTTPS 自定义端口与列表中的 User-Agent，保留原分组；设置中可刷新订阅，先尝试 GitHub 原始地址，再尝试上游 README 的镜像，失败保留旧目录。数量表示格式可识别，不表示实测全部可播放。网络、运营商、地区与源状态会影响播放。

影视搜索改为逐源返回即时显示；已有剧集详情在进程内缓存 10 分钟、最多 64 项，避免点击后再次请求同一详情。点播媒体使用 64 MB 磁盘 LRU 缓存（直播不缓存），启动缓冲从 1.5 秒调整为 0.75 秒，保留独立的重新缓冲参数和原有重试；启用解码器回退。目录在首页后台预读并缓存，导入/刷新时失效，换页和进入播放不再重复解析上千条地址。

当前 TVLive 仓库仍是空源播放器框架，没有实际电视或影视地址；未虚构 TVLive 影视站点，网络影视仍使用导入的标准 API 与自有播放列表。单目录 JSON / M3U / TXT 上限增加到 3,000 项，仍限制 1 MB 与每个频道 8 个地址。
